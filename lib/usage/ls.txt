usage: collie ls [-a]

List live tasks: id, status, priority, session (* exists, - none), agent
(most urgent run state), repos, needs (answer, findings, review, reply,
stalled, start, blocked:<ids>, -). On a terminal, columns are aligned with
a header; otherwise, rows are tab-separated without a header. -a includes
done and archived. The terminal display may show a quiet hint for long-running
hook-based `working` runs (`@collie-quiet`, default 1800 seconds); it does not
change state or piped output. Read-only.
